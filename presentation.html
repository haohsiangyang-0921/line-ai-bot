🎯 想解決的問題

日常查資料、撰寫文本與概念問答常需切換專用 AI 軟體；傳統聊天機器人遇到貼圖或空白訊息時，常發生「已讀不回」或崩潰報錯的痛點。

👥 目標對象與核心價值

鎖定學生、自學者與一般 LINE 用戶。透過天天都在用的通訊軟體，直接獲得 Gemini 大語言模型的 24 小時即時解答與防呆保護。

🌟 第一版核心功能

  • Gemini 智慧問答：即時解析使用者自然語言並生成繁體中文回覆。
  • 嚴格簽章檢驗：HMAC-SHA256 驗證 X-Line-Signature，確保請求安全性。
  • 雙模式自動備援：無金鑰自動降級為 Echo 測試模式。

🚀 v2.0 改善版核心升級

  • 不支援輸入友善導引：收到貼圖或照片時主動提示「僅支援純文字」，告別已讀不回！
  • 空白輸入防呆檢驗：自動過濾純空格並溫馨引導使用者提問範例。
  • 內建指令系統：支援 /help（使用指南）與 /about（狀態）。

🛠️ 協作方式與指令範例

協作工具：Antigravity Agent (Gemini 3.8 Flash)

代表性 Prompt 指令：
「請規劃一個以 Python FastAPI 與 LINE Bot SDK v3 為核心的 AI 機器人，並串接 Google Gemini 模型進行問答。」

🔍 檢查並修正 AI 產出的真實案例

  • 案例一：Windows 批次檔換行錯誤
    AI 最初產生的 .bat 包含 Linux LF 換行與特殊字元，導致 Windows 報錯 'cho' 不是內部命令。經檢查後改寫為二進位 CRLF (\r\n) 成功解決。
  • 案例二：模型名稱過期修正
    AI 原先採用 gemini-2.5-flash，連線時遭 Google API 提示 404 已下線。經手動查詢模型清單後，修正為最新的 gemini-3.8-flash。

🎓 學習收穫與心得

  • 掌握 Webhook 核心原理與非同步 API 實作。
  • 理解反向代理（ngrok）與 HMAC 數位簽章防偽價值。
  • 深刻體會「工程師親自除錯與驗證」是 AI 協作不可或缺的核心環節。
