# 🤖 LINE AI 智慧對話小助理 (改善版)

一個整合 **FastAPI**、**line-bot-sdk v3** 與 **Google Gemini 3.8 Flash** 的智慧 LINE 官方帳號機器人。具備即時 AI 問答、一鍵背景隱藏執行與關閉、不支援訊息友善導引等特色。

---

## 📌 專題介紹
* **專題名稱**：LINE AI 智慧對話小助理 (改善版)
* **使用對象**：學生、自學者與一般 LINE 使用者。
* **想解決的問題**：
  * 使用者需要隨時隨地查閱資訊、撰寫範本、翻譯或解題，但切換外部 AI App 繁瑣。
  * 透過 LINE 這個人人日常都在使用的通訊軟體，直接獲得 Gemini 大語言模型的即時協助。
  * 解決傳統聊天機器人本機測試需開兩個黑視窗干擾桌面的問題，以及面對非文字訊息時「已讀不回」的痛點。

---

## ✨ 核心功能與改善版特色

### 1. 核心功能
* **AI 智慧問答**：串接 Google 最新 `gemini-3.8-flash` 模型，提供快速且準確的繁體中文問答。
* **簽名安全檢驗**：使用 LINE 官方 `WebhookParser` 進行 HMAC-SHA256 簽章比對，防止偽造 Webhook 請求。
* **雙模式自動備援**：若未填入 Gemini API Key，系統自動切換為 Echo（鸚鵡學舌）測試模式，不中斷服務。

### 2. 改善版新增功能 (v2.0 改進亮點)
* **🚀 本機運行流程大幅改善（免開黑視窗）**：原本需要在電腦桌面上常駐開啟兩個終端機視窗（FastAPI 伺服器與 ngrok 穿透），佔用螢幕且易被誤關；改善為製作腳本，實現「一鍵在電腦背景隱藏運行」與「一鍵停止關閉」，桌面乾淨無干擾。
* **💡 不支援輸入友善導引**：收到貼圖或照片時主動提示「僅支援純文字對話」，減少已讀不回造成的疑惑。

## ⚙️ 快速安裝與設定指南

### 1. 複製專案與安裝依賴
```bash
git clone https://github.com/haohsiangyang-0921/line-ai-bot.git
cd line-ai-bot
python -m venv venv
.\venv\Scripts\pip install -r requirements.txt
```

### 2. 環境變數配置 (`.env`)
複製 `.env.example` 為 `.env`，並填入以下金鑰：
```env
# 請於 LINE Developers Console 取得
LINE_CHANNEL_SECRET=your_line_channel_secret_here
LINE_CHANNEL_ACCESS_TOKEN=your_line_channel_access_token_here

# 請於 Google AI Studio (https://aistudio.google.com/) 免費取得
GEMINI_API_KEY=your_gemini_api_key_here
```
> ⚠️ **安全性提醒**：`.env` 已列入 `.gitignore`，切勿將真實金鑰推播至公開儲存庫。

### 3. 本機啟動方式
* **一鍵隱形啟動（推薦）**：雙擊執行 `一鍵隱藏啟動.vbs`（完全不跳黑色視窗，背景常駐運行）
* **一鍵關閉終止**：雙擊執行 `一鍵關閉停止.bat`
* 一般除錯啟動：雙擊執行 `run_server.bat` 與 `run_ngrok.bat`

## 🚧 已知限制與未來展望
1. **目前能用到雲端的軟體皆須付費**：嘗試部屬至 Render、Zeabur 等雲端時皆遇信用卡或付費買伺服器門檻，無法輕易免費全天候託管。
2. **讓一鍵執行與關閉更正常**：持續優化背景執行腳本，改善偶爾進程殘留的現象。
3. **遇到不支援的貼圖文字也能更穩定回應**：持續強化例外處理與非文字訊息應答能力。
